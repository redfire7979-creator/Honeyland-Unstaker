ℹ About Classification▸

Recoverable: held by the live Honeyland Core program (classic tokens) or the known active Generations staking pool. Can be unfrozen right now with the Recovery tool.

Not recoverable: frozen by the old Honeyland program, which has been deleted on-chain (bytecode gone). No instruction exists that can unfreeze these - confirmed permanent, not fixable by any tool.

Can't tell yet: a pool or delegate this tool doesn't recognize, a compressed asset (not supported yet), or a temporary lookup failure - not confirmed either way. Try rescanning if you see a lot of these.
